THIRANEX TASK 4 - REAL-WORLD RETAIL DATA PROJECT

Project Title:
Retail Sales Analysis and Customer Insights

Objective:
Analyze a real-world retail transaction dataset to discover sales trends, top-performing products, geographic performance, customer value, and relationships between sales metrics.

Dataset:
This project uses the Online Retail dataset from the UCI Machine Learning Repository.

The dataset contains transactions from 1 December 2010 to 9 December 2011 for a UK-based non-store online retailer.

Dataset features used:
- Description
- Quantity
- InvoiceDate
- UnitPrice
- CustomerID
- Country

Source:
https://archive.ics.uci.edu/dataset/352/online+retail

DOI:
https://doi.org/10.24432/C5BW33

Tools:
- Python
- Pandas
- Matplotlib
- UCI ucimlrepo

Analysis Performed:
1. Data loading from UCI
2. Data cleaning
3. Revenue calculation
4. Monthly revenue trend
5. Top products by revenue
6. Top countries by revenue
7. Top customers by revenue
8. Revenue by day of week
9. Quantity vs revenue analysis
10. Customer RFM analysis
11. Correlation analysis
12. Business conclusions and recommendations

How to Run:
Install the required dependencies:

pip install -r requirements.txt

Then run:

python Task4.py

The script automatically retrieves the UCI Online Retail dataset using ucimlrepo and generates the analysis figures.

Data Cleaning:
- InvoiceDate was converted to datetime format.
- Rows with missing essential values were removed.
- Transactions with non-positive quantities were removed.
- Transactions with non-positive unit prices were removed.
- Revenue was calculated as:

Revenue = Quantity × UnitPrice

The dataset version retrieved through ucimlrepo provides the features used in this analysis without InvoiceNo. Therefore, cancellation invoices cannot be identified using invoice-number prefixes.

Customer RFM analysis uses records with an available CustomerID.

RFM Analysis:
- Recency: how recently a customer made a purchase.
- Frequency: how frequently a customer appears in the transaction records.
- Monetary: total revenue generated by a customer.

The analysis included 4,338 customers with available CustomerID values.

Correlation Analysis:
The correlation analysis examined Quantity, UnitPrice, and Revenue.

The strongest relationship was between Quantity and Revenue, with a correlation of approximately 0.91, indicating a strong positive relationship.

Key Findings:
1. The highest-revenue month was November 2011, with revenue of approximately £1.51 million.
2. The United Kingdom generated the highest revenue among the countries analyzed, at approximately £9.03 million.
3. DOTCOM POSTAGE was the highest-revenue product, generating approximately £206,248.77.
4. Customer 14646 was the highest-value customer, generating approximately £280,206.02.
5. Quantity and revenue showed a strong positive correlation of approximately 0.91.
6. Monthly and weekday revenue patterns can support inventory, marketing, and staffing decisions.
7. Product-level quantity and revenue analysis can help identify high-performing products.
